# WJSBaseball

언리얼 엔진 5.5와 C++로 만든 멀티플레이 숫자 야구 게임입니다.

강의에서 만든 채팅 프로젝트를 바탕으로 숫자 판정과 시도 횟수,
승패 처리 등을 추가했습니다.

## 구현 내용

플레이어가 채팅창에 세 자리 숫자를 입력하면 서버에서 정답과 비교합니다.

숫자와 위치가 같으면 Strike, 숫자만 같으면 Ball로 처리하고
일치하는 숫자가 없으면 OUT을 출력합니다.

잘못된 입력으로 기회를 잃지 않도록 세 자리 숫자인지,
중복된 숫자나 0이 들어갔는지도 검사합니다.

플레이어마다 3번의 기회가 주어집니다.
먼저 3 Strike를 맞히면 승리하고,
모든 플레이어가 기회를 사용하면 무승부로 처리한 뒤 게임을 초기화합니다.

추가로 턴과 제한 시간을 구현했습니다.
자신의 턴에만 숫자를 입력할 수 있고,
시간 안에 입력하지 않으면 기회가 한 번 줄어든 뒤 다음 플레이어에게 턴이 넘어갑니다.

현재 턴과 남은 시간은 GameState를 통해 각 클라이언트에 동기화했습니다.

## 구현하면서 발생한 문제

처음에는 서버에서도 UI를 생성하려고 해서 크래시가 발생했습니다.
`IsLocalController()`를 확인한 뒤 로컬 플레이어만 위젯을 만들도록 수정했습니다.

시도 횟수가 실제보다 한 번 늦게 표시되는 문제도 있었습니다.
서버에서 횟수를 먼저 증가시킨 뒤 메시지를 만들도록 순서를 변경해서 해결했습니다.

## 실행 방법

언리얼 엔진 5.5에서 프로젝트를 열고 다음과 같이 설정합니다.

- Net Mode: Play As Client
- Number of Players: 2
- Launch Separate Server 사용

게임 실행 후 현재 턴인 플레이어가 채팅창에 세 자리 숫자를 입력하면 됩니다.
